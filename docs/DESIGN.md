# DESIGN — визуальный канон TroutMap Europe
Источник: ручной разбор собственной системы + вайб-эталон troutareacz.cz
(прямой фетч эталона заблокирован сетевой политикой; зафиксирован дух:
спортивный trout-area портал — тёмная вода, чистая типографика, фирменная
форель). Зафиксировано: 2026-07-30. Канон обязателен для всех UI-правок,
включая автономные волны самоулучшения.

## Тезис системы
Outdoor-сервис уровня AllTrails/Airbnb для эриа-форелистов: тёмно-бирюзовая
«вода» + коралловый «воблер» как единственный акцент действия. Всё читается
одной рукой на телефоне поверх спутниковой карты. Иконография — фирменные
линейные SVG с мотивом форели; эмодзи в UI-хроме запрещены (допустимы только
как контент: флаги стран, погодные значки WMO).

## Токены — типографика
Manrope (Google Fonts, фолбэк system-ui) — единственное семейство.
Веса: 800 заголовки/имена, 700 кнопки/бейджи, 400–600 текст.
Секции карточки: 12px/800/uppercase/letter-spacing 0.8px.
Запрещено: второе семейство, курсив, веса ниже 400.

## Форма и поверхность
Радиусы: пилюли (кнопки/чипы/поиск) — 999px; карточки/поля — 12–18px
(--radius-sm/--radius); шторки/модалки — 22px (--radius-lg) сверху.
Тени: --shadow-sm на плавающем хроме, --shadow на FAB/шторках; без жёстких
чёрных теней. Отступы контента модалок: 18px. max-width: 720px (список),
640px (модалки), 420px (десктоп-шторка).

## Иконография (фирменная)
Спрайт в index.html: линейные 24×24, stroke 1.8, round caps, currentColor.
Обязательный мотив — форель (#i-trout: бренд, сплэш, пины, помощник).
Размеры: .ico 18px, .ico--chip 15px, .ico--badge 13px, .ico--title 21px,
.ico--hero 58px, .ico--pin 17px. Новая иконка = новый symbol в том же стиле,
не эмодзи и не сторонний набор.

## Do / Don't
- Do: спутник по умолчанию; подсветка выбранного всегда явная (цвет + ✓);
  один коралловый акцент на экран; тексты только через реестр i18n (ru/en/cs).
- Don't: эмодзи в хроме UI; тёмные тайлы «Схемы»; второй шрифт; больше
  двух уровней тени; блокирующие анимации дольше 5 с без кнопки «пропустить».

## bar.md-заготовка (планка каждой итерации дизайн-лупа)
1. На каждом экране ровно один коралловый акцент-действие, не больше.
2. Выбранный пункт любого списка/пикера различим без чтения (цвет + ✓/бордер).
3. В UI-хроме ни одного эмодзи — только SVG-спрайт (флаги/погода — контент, можно).
4. Тач-мишени ≥ 44px, текст ≥ 11px, бейджи проходят WCAG AA в обеих темах.
5. Иконки одного веса штриха (1.8) и одного размера в пределах ряда.
6. Карточка читается на спутниковой подложке: непрозрачные поверхности, без «просвечивания».
7. Скриншот-сет (tests/design-shots.js) без визуальных регрессий против прошлой итерации.

## Как гоняется луп
`node tests/design-shots.js` → скриншоты всех ключевых экранов в
`/tmp/design-shots/` → критик (агент или человек) сверяет с bar.md →
правки → повтор до чистого прохода. Волны самоулучшения обязаны гонять
луп перед PR.
