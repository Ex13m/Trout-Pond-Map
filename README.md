# 🎣 TroutMap Europe

Интерактивная карта коммерческих форелевых водоёмов Европы для ловли в стиле
**trout area** — ультралайт-спиннинг по принципу «поймал — отпустил» (catch & release).

## Возможности

- 🗺️ **Карта** на Leaflet с кластеризацией маркеров (CARTO basemap, тёмная тема — автоматически)
- 📇 **Детальные карточки** водоёмов: описание, виды рыб, правила, цены, сезон, инфраструктура, сайт
- 🌦️ **Живая погода** на водоёме (Open-Meteo): текущие условия, прогноз на 3 дня, давление, ветер + эвристический «прогноз клёва»
- 🔎 **Поиск и фильтры**: по названию/городу/стране, только C&R, круглогодичные, фильтр по стране
- 📍 **Геолокация**: ближайшие водоёмы с расстоянием
- 📱 **Mobile-first**: нижняя шторка (bottom sheet) с жестами, safe-area, крупные тач-зоны
- 🎨 Атмосферные иллюстрации сгенерированы через **Higgsfield AI** (soul_location)

## Запуск

Статический сайт без сборки. Откройте `index.html` или поднимите любой статический сервер:

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

Подходит для GitHub Pages: Settings → Pages → Deploy from branch.

## Структура

```
index.html        — разметка, подключение Leaflet/шрифтов
css/styles.css    — дизайн-система (mobile-first, dark mode)
js/data.js        — база водоёмов (window.VENUES)
js/changelog.js   — история версий для окна «Что нового»
js/app.js         — карта, фильтры, шторка, погода, версии
CHANGELOG.md      — полная история изменений (SemVer)
```

## Версионирование

Версия показывается на сплэше и в «О проекте». При выходе новой версии
посетитель один раз увидит окно «Что нового» (отметка хранится в
localStorage). Чтобы выпустить новую версию: добавьте запись первой в
`js/changelog.js` и продублируйте её в `CHANGELOG.md`.

## Данные

База собрана из открытых источников: сайты водоёмов, федерации, календари
соревнований trout area. Цены и правила **ориентировочные** — перед поездкой
сверяйтесь с сайтом водоёма. Фото карточек — иллюстративные (AI),
не являются фотографиями конкретных водоёмов.

Хотите добавить водоём или поправить данные — PR в `js/data.js`.
